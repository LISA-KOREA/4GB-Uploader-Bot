# Telegram URL Uploader Bot — Full Source Code

A powerful, all-in-one Telegram bot that lets users upload files from various sources including YouTube, Torrents, Magnet links, Direct URLs, and more — with advanced features like custom captions, split uploads, thumbnails, and auto-unzipping.

---

## 🚀 Features

- **YouTube Video Downloading** (via `yt-dlp`)
- **Torrent & Magnet Link Support**
- **Supports Files up to 4GB**
- **Split Uploading for Large Files**
- **Automatic ZIP/UNZIP Extraction**
- **Custom Thumbnails**
- **Video to File Conversion**
- **Custom Captions**
- **File Rename Support**
- **Auto-deletion of Expired Tasks**
- **MongoDB Integration**
- **Premium Plan Support (Free, Silver, Gold)**

---

## ⚙️ Requirements

- Python 3.10+
- MongoDB
- Heroku or VPS
- ffmpeg, aria2, unzip
- yt-dlp
